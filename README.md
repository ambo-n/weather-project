# Weather Data Processor

## Overview

This project provides a set of Python functions to process weather data from CSV files. It transforms raw numerical and ISO-formatted data into human-readable summaries, making it easier to interpret weather conditions.

## Features

The project includes the following functions:

- **Format Temperature:** Takes a temperature and returns it as a formatted string with the degree (°) and Celsius (°C) symbols.
- **Convert ISO Date:** Converts an ISO-formatted date (YYYY-MM-DD) into a more human-readable format (e.g., "January 1, 2024").
- **Fahrenheit to Celsius:** Converts a temperature from Fahrenheit to Celsius.
- **Calculate Mean:** Computes the mean (average) value from a list of numbers.
- **Read CSV File:** Reads a CSV file and stores the data in a list.
- **Find Minimum Value:** Calculates the minimum value in a list of numbers.
- **Find Maximum Value:** Calculates the maximum value in a list of numbers.
- **Generate Summary:** Outputs a summary for the given weather data, including min, max, and mean temperatures.
- **Generate Daily Summaries:** Outputs daily summaries of the weather data.
